# Bundled fonts

Every Gravity PDF install ships these faces, so a PDF renders correctly with no download and no setup. They are
committed artefacts, regenerated by hand — there is no build step and no checksum job. Regenerate them only to
pick up an upstream release, and re-record the versions below when you do.

Both families are also registered with mPDF under plugin-prefixed keys (`gfpdf-arimo`, `gfpdf-dejavu-symbols`)
so they can never collide with a catalogue entry or a user upload.

## Arimo — `gfpdf-arimo`

Upstream: <https://github.com/googlefonts/arimo> `fonts/ttf/`, commit `4a6255f269916ae7ad3fc2706b0935e7621396b8`.
Licence: SIL Open Font License 1.1 (`OFL-Arimo.txt`), no Reserved Font Name.

Arimo covers Latin, IPA, combining diacritics, Greek (+ Extended), Cyrillic, Vietnamese and Hebrew in all four
faces, and its metrics match Arial, so templates asking for Arial or Helvetica keep their layout.

The four faces are **dehinted**: TrueType hinting is stripped and nothing else changes. Outlines, glyph order,
cmap and layout tables are byte-identical to upstream. That is a third off the file size, and it also shrinks
every generated PDF, because mPDF embeds subsets with their hint instructions and no PDF viewer runs them.

```
python3 dehint.py Arimo-Regular.ttf Arimo-Regular.ttf   # see below; repeat per face
```

```python
# dehint.py
import sys
from fontTools.ttLib import TTFont
from fontTools.ttLib.tables import ttProgram

font = TTFont(sys.argv[1])
for table in ('cvt ', 'fpgm', 'prep', 'gasp', 'hdmx', 'LTSH', 'VDMX'):
    if table in font:
        del font[table]
empty = ttProgram.Program()
empty.fromBytecode(b'')
glyf = font['glyf']
for name in font.getGlyphOrder():
    glyph = glyf[name]
    glyph.expand(glyf)
    if hasattr(glyph, 'program'):
        glyph.program = empty
font['maxp'].maxSizeOfInstructions = 0
font.save(sys.argv[2])
```

## DejaVu Sans Symbols — `gfpdf-dejavu-symbols`

Upstream: DejaVu Sans 2.34 (`DejaVuSans.ttf` as shipped in `GravityPDF/mpdf-core-fonts`, commit
`76b7d7a85a399f81fcda266aaf27a5fa026e4d4e`). Licence: Bitstream Vera (`LICENSE-DejaVu.txt`) — modification and
redistribution are permitted provided the derived name contains neither "Bitstream" nor "Vera".

A substitution-only supplement, never offered as a document font. It carries the symbol blocks Arimo lacks:
arrows, maths, technical, enclosed alphanumerics, box drawing, geometric shapes, miscellaneous symbols and
dingbats. Most importantly it carries ✔ U+2714 and ✖ U+2716, which the Consent and Terms of Service fields emit
and no candidate sans-serif except DejaVu has. Without it mPDF falls back to unembedded ZapfDingbats, which
renders as a notdef box in PDF/A and PDF/X modes.

```
python3 -m fontTools.subset DejaVuSans.ttf --output-file=DejaVuSansSymbols.ttf \
  --unicodes=U+2190-23FF,U+2460-27BF,U+2B00-2BFF --layout-features='*' --notdef-outline
```
