# Bundled fonts

Every Gravity PDF install ships these faces, so a PDF renders with no font download. They are committed artefacts,
regenerated by hand: there is no build step. Regenerate them only to pick up an upstream release, and update the
version below when you do.

## Arimo (`arimo`)

Upstream: <https://github.com/googlefonts/arimo> `fonts/ttf/`, version 1.33, commit
`4a6255f269916ae7ad3fc2706b0935e7621396b8`. Licence: SIL Open Font License 1.1 (`OFL-Arimo.txt`), no Reserved Font
Name.

The files are prefixed `gfpdf-` so they never collide with the `Arimo-*.ttf` copies premium templates put in the
PDF fonts folder.

The four faces are **dehinted**: TrueType hinting is stripped, which takes a third off the file size and off every PDF
that embeds them. A rebuild matches these files byte for byte. Run once per face with fontTools 4.68.0:

```
python3 -I dehint.py Arimo-Regular.ttf gfpdf-Arimo-Regular.ttf
```

```python
# dehint.py: the same steps as utils/dehint_fonts.py in GravityPDF/mpdf
import sys
from fontTools.ttLib import TTFont

font = TTFont(sys.argv[1], recalcBBoxes=False, recalcTimestamp=False)
for table in ('cvt ', 'fpgm', 'prep', 'gasp', 'hdmx', 'LTSH', 'VDMX', 'DSIG'):
    if table in font:
        del font[table]
font['glyf'].removeHinting()
font['maxp'].maxSizeOfInstructions = 0
font.save(sys.argv[2])
```

## DejaVu Sans symbols (`gfpdf-dejavu-symbols`)

The symbols Arimo lacks: the arrows, maths, technical, enclosed, box-drawing, geometric, misc-symbol and dingbat
blocks, including the ✔ and ✖ the Consent and Terms of Service fields draw. It is only used to fill in characters, so
it isn't offered as a font in the settings.

Source: the dehinted `DejaVuSans.ttf` 2.34 the core fonts download, GravityPDF/mpdf-core-fonts v1.1.2 (git blob
`907f176e4efc7e7372fc8be6bc6a1e70ef6f5f8e`). Licence: Bitstream Vera and Arev (`LICENSE-DejaVu.txt`); a modified
copy must not be named "Bitstream" or "Vera". Subset with fontTools 4.68.0 (1,108 glyphs):

```
python3 -I -m fontTools.subset DejaVuSans.ttf --unicodes=U+2190-23FF,U+2460-27BF,U+2B00-2BFF \
  --layout-features='*' --notdef-outline --output-file=gfpdf-DejaVuSansSymbols.ttf
```

## Core font manifest (`core-fonts.json`, `core-fonts.php`)

Not fonts: the name, download URL, size and git blob SHA-1 of each mPDF core font, which PDFs download when they need
one. `yarn prebuild:core-fonts` fetches the JSON from the GitHub contents API and writes the PHP array from it with
`tools/release/php-payload.php`; the plugin reads the PHP. Don't edit either by hand.

`core-fonts-v1.0.0.php` is the same list for mpdf-core-fonts v1.0.0, the files the removed Core Font installer
downloaded, before the core fonts were dehinted. It's the core source's `legacy_manifest`: the 6.19 upgrade adopts
custom font records of these files and deletes the unmodified ones it doesn't need. It's frozen, and goes when that
upgrade routine does. It was written with:

```
bash tools/release/json-payload.sh "https://api.github.com/repos/GravityPDF/mpdf-core-fonts/contents/?ref=v1.0.0" tmp/core-fonts-v1.0.0.json
php tools/release/php-payload.php tmp/core-fonts-v1.0.0.json fonts/core-fonts-v1.0.0.php
```
