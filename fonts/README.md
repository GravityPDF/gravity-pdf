# Bundled fonts

Every Gravity PDF install ships these faces, so a PDF renders with no font download. They are committed artefacts,
regenerated by hand: there is no build step. Regenerate them only to pick up an upstream release, and update the
version below when you do.

## Arimo (`arimo`)

Upstream: <https://github.com/googlefonts/arimo> `fonts/ttf/`, version 1.33, commit
`4a6255f269916ae7ad3fc2706b0935e7621396b8`. Licence: SIL Open Font License 1.1 (`OFL-Arimo.txt`), no Reserved Font
Name.

The files are prefixed `GravityPDF-` so they never collide with the `Arimo-*.ttf` copies premium templates put in the
PDF fonts folder.

The four faces are **dehinted**: TrueType hinting is stripped and nothing else changes, which takes a third off the
file size and off every PDF that embeds them. Run once per face with fontTools 4.59.2:

```
python3 -I dehint.py Arimo-Regular.ttf GravityPDF-Arimo-Regular.ttf
```

```python
# dehint.py
import sys
from fontTools.ttLib import TTFont
from fontTools.ttLib.tables import ttProgram

font = TTFont(sys.argv[1])
for table in ('cvt ', 'fpgm', 'prep', 'gasp', 'hdmx', 'LTSH', 'VDMX'):
    if table in font:
        del font[table]
empty = ttProgram.Program()
empty.fromBytecode(b'')
glyf = font['glyf']
for name in font.getGlyphOrder():
    glyph = glyf[name]
    glyph.expand(glyf)
    if hasattr(glyph, 'program'):
        glyph.program = empty
font['maxp'].maxSizeOfInstructions = 0
font.save(sys.argv[2])
```

fontTools stamps the save time into the `head` table, so a rebuild matches these files in size but not byte for byte.
